# HD-EEG-Spindle-Connectivity
Matlab functions for HD-EEG analyses of spindles connectivity 
LiveScript_01: Spindles in coincidence accross hd-EEG montage; 
The source space is defined in terms of Fourier modes over the cortical graph; 
The inverse problem is solved in the Fourier domain using the Maximum Entropy on
the Mean with a reduced prior (null hyp)
Expressed in the Fourier domain, the lead fields are selected such that the gain matrix 
is controlled for its conditionning.
